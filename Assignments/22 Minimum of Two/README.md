# Instructions  
Write a program that takes two numbers as input. Print the smaller number.

  ## Steps
  1. Get two inputs `int(input())`
  2. `print()` the smaller number 

  ## Example
  ### Input
  `12`

  `13`

  ### Output
  `12`
