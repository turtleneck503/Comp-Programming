# Instructions  
  Write a program that takes one integer as input - a year number. If this year is a leap year, print LEAP. Otherwise, print COMMON.

  ## Steps
  1. Get one `int(input())`
  2. If this year is a leap year, print LEAP
  3. Otherwise, print COMMON

  ## Example
  ### Input
  `2012`

  ### Output
  `LEAP`

  ## Hints
  * A year is a leap year if its number is exactly divisible by 4 AND is not exactly divisible by 100
  * A year is always a leap year if its number is exactly divisible by 400.
