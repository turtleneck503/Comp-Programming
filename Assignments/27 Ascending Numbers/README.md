# Instructions  
  Write a program that takes three integers as `int(input())`. If the numbers are inputted in ascending order, print `YES`. If not, print `NO`.
  
  ## Steps
  1. Get three integers as `int(input())`
  2. If the numbers are in ascending order, print `YES`
  3. If not, print `NO`.

  ## Example
  ### Input
  `101`
  
  `150`
  
  `267`

  ### Output
  `YES`
