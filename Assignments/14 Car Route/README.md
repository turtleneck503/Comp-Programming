# Instructions  
A car can cover a distance of `N` miles per day. How many days will it take this car to cover a route of `M` miles? The program will get two numbers as input, `N` and `M`.

  ## Steps
  1. Get two `input()`s from the user. The first is the number of miles a car can drive in one day. The second is the number of miles in the route.
  2. `print()` the number of days it will take the car to drive the route.

  ## Example
  ### Input
  `700`
  
  `750`

  ### Output
  `2`
  
  ## Hint
  At the top of your code put the line below to import the `ceil()` function.
  
  `from math import ceil`

  You will need to use this `ceil()` function to complete the assignment. [Click here](https://www.w3schools.com/python/ref_math_ceil.asp) for more information on this function.
