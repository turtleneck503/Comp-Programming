# Instructions  
  Write a program that takes one number as input, then outputs the last digit of that number.

## Steps
  1. Get one `input()` from the user. This will be a number.
  2. `print()` the last digit of that number.
  3. Hint: If you divide a number by 10, the remainder will be the final digit.

## Example program
### Input
`179`

### Output
`9`
