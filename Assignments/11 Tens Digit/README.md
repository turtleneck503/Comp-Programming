# Instructions  
Write a program that gets one number as input, then prints its tens digit.

## Steps
1. Get one number as `input()` from the user.
2. `print()` the tens digit of this number
3. Hint: dividing a number by 10 removes the ones digit. Divide by 10 again, and the remainder is the original tens digit.

## Example
### Input
`179`

### Output
`7`
