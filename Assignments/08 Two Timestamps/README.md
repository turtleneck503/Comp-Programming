# Instructions  
A timestamp is three numbers: a number of hours, minutes and seconds. Given two timestamps, calculate how many seconds is between them. The moment of the first timestamp will never be after the moment of the second timestamp.

  ## Steps
  1. You will get six inputs from the user - a number of hours, minutes, and seconds for two different timestamps.
  2. Calculcate and print the number of seconds between each timestamp.
  3. The first timestamp will always be before the second timestamp.

  ## Example
  ### Input
  `2`
  
  `3`
  
  `4`
  
  `4`
  
  `7`
  
  `28`

  ### Output
  `7464`
