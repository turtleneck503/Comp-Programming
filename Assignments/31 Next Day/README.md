# Instructions  
  Write a program that takes two numbers as input - a month (1 = January, 12 = December) and a day (1 - 31). Print the month and day number of the next day.

  ## Steps
  1. Get two `int(input())` - a month and a day.
  2. Print the month and day of the next day.

  ## Example
  ### Input
  `3`

  `30`

  ### Output
  `3`
  
  `31`
