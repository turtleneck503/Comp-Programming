# Instructions  

Write a program that takes one number as `int(input())`. This will be a positive number. If it has three digits, print `YES`. Otherwise, print `NO`.

  ## Steps
  1. Get one number as `int(input())`
  2. If the number has three digits, print 'YES'
  3. Otherwise, print `NO` 

  ## Example
  ### Input
  `159`

  ### Output
  `YES`
