# Instructions  

Write a program that gets one number as input. If it is positive, print "YES", otherwise, print "NO".

  ## Steps
  1. Get one integer as `input()`
  2. If the number is positive, print "YES"
  3. Else, print "NO"

## Example
### Input
`-12`

### Output
`NO`
