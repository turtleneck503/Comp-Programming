# Instructions  
Write a program that takes two numbers as input. If at least one of them is odd, print YES. Otherwise, print NO.

  ## Steps
  1. Get two inputs `int(input())`
  2. If at least one of them is odd, print YES
  3. Otherwise, print NO

  ## Example
  ### Input
  `12`

  `13`

  ### Output
  `YES`
