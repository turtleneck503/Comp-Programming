# Instructions  
  Write a program that takes one number as input - a month (1 = January, 12 = December). Print the number of days this month has in the year 2022.

  ## Steps
  1. Get one `int(input())`
  2. Print the number of days in this month for the year 2022 

  ## Example
  ### Input
  `1`

  ### Output
  `31`

  ## Hints
  * You can do this challenge only using one if-elif-else statement. Your code should look something like this:

```
if(check if the month was February):
  print(28)
elif(check if the month has 30 days):
  print(30)
else:
  print(31)
```
