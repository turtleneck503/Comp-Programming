# Instructions  
  Your program should take one `input()`, the number of minutes passed since midnight. Print the time that would show on a digial clock.

  For example, if the input is 150 that means 150 minutes have passed since midnight. This means it is currently 2:30 am, and your program should print `2 30`.

  ## Steps
  1. Get one `input()` from the user - this is the number of minutes that have passed since midnight.
  2. `print()` the time.

  ## Example
  ### Input
  `150`

  ### Output
  `2 30`
