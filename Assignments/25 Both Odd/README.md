# Instructions  
Write a program that takes two numbers as input. If both are odd, print YES. Else, print NO.

  ## Steps
  1. Get two inputs `int(input())`
  2. If both are odd, print YES
  3. If not, print NO

  ## Example
  ### Input
  `12`

  `13`

  ### Output
  `NO`
