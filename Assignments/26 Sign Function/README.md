# Instructions  
Write a program that gets one input - an integer. If this number is postive, print `1`. If it's negative, print `-1`, and if it's zero, print `0`.

  ## Steps
  1. Get one `int(input())`
  2. If the number is positive, print `1`
  3. If the number is negative, print `-1`
  4. If the number is zero, print `0` 

  ## Example
  ### Input
  `5`

  ### Output
  `1`
