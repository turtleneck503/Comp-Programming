# Instructions  
Write a program that reads the length of the base and the height of a right-angled triangle and prints the area. Every number is given on a separate line.

  ## Steps
  1. Get `B` (the length of the base of the triangle) as the first `input()` from the user.
  2. Get `H` (the height of the triangle) as the second `input()` from the user.
  3. Print the area of the triangle
  4. Area = (B * H) / 2

  ## Example
  ### Input
  `3`

  `5`

  ### Output
  `7.5`
